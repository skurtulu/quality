# SCHADENSMELDUNG FÜR TASCHEN
[GÖRSEL: damagebags.jpg, 300x300, orta]
In unserer wöchentlichen Quip-Liste finden Sie einen Link zum Melden beschädigter Taschen: https://console.harmony.a2z.com/amzl-bat-tools/ Für diese Aufgabe benötigen Sie einen Avery-Scanner zum Scannen der QR-Codes. Scannen Sie zunächst den QR-Code unter diesem Link, um mit dem Scannen beschädigter Taschen zu beginnen. 
-> 1. Land auswählen (DE) → Standort auswählen (DAH1) 
→ 2. Taschen auswählen 
→ 3. Szenario auswählen (Beschädigt)
→ 3a. Problem beschreiben (Sie müssen für jede Tasche das richtige Problem auswählen, bevor Sie sie scannen) 
→ 4. Tasche mit dem Avery-Scanner scannen
[GÖRSEL: exclamation.jpg, 150x150, sol] 
Wie entscheidet man, ob eine Tasche beschädigt ist?
-> Wenn einer der Reißverschlüsse kaputt ist,
-> Wenn zwei von drei QR-Codes beschädigt sind,
-> Wenn die Tasche zu stark verschmutzt ist und sich nicht reinigen lässt,
-> Wenn sie innen oder außen beschädigt ist,
-> Wenn sie einen größeren Riss hat,
dann können wir sie in den Wagen für beschädigte Taschen legen, der sich in der Nähe des Bereichs mit den roten Etiketten befindet.
